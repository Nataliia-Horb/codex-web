# Junk or No

A friendly Next.js app with Tailwind CSS that lets someone type a food name and receive a gentle verdict: usually junk, healthy, or neutral.

## Getting started

Install dependencies and run the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Build for production:

```bash
pnpm build
pnpm start
```

The app uses simple keyword matching in `app/page.tsx` and includes English and Russian examples.
